# Matheus Isperling

Official portfolio website for Matheus Isperling, a hair stylist specialized in textured and curly hair.

## Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Vercel

## Project Goals

- Showcase portfolio.
- Present brand identity.
- Display Google reviews.
- Provide contact and booking links.
